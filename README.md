# FRAME — CodeAlpha Image Gallery
 https://areebashahzadi-dot.github.io/CodeAlpha-image-gallery/
A responsive, editorial-style photo gallery built with HTML, CSS and vanilla JavaScript.

## Features
- 24 sample photos across Nature, Architecture and Travel.
- Responsive asymmetrical photo grid for desktop, tablet and mobile.
- Category filters and live photo count.
- Full-screen lightbox with Previous and Next navigation.
- Keyboard controls: Left Arrow, Right Arrow and Escape.
- Hover zoom, image overlays, smooth transitions and lazy loading.
- Accessible labels, descriptive alt text and reduced-motion support.

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Internet is needed for the sample images and Google Fonts.

## Files
- `index.html` — page structure and gallery content
- `style.css` — design, effects and responsive layout
- `script.js` — filters and lightbox interactions

## Customize
Replace the remote image URLs in `index.html` with images you have permission to use. Keep `data-category` values as `nature`, `architecture` or `travel` so filters continue to work.

## GitHub
Create a public repository named `CodeAlpha_ImageGallery` and upload all four project files.
